Polish Roadmap

Sixteen things that would make a run feel finished. I found them by reading the game as it is today. None is a bug fix, and none repeats an open-list item or something you've already decided against.

How to answer: each item has my answer on it. Reply the way you do with the open list: “all yes”, or “yes except 9 and 13”. Whatever you say yes to goes onto the open list, and gets ticked off there.

Phase 1 · one build · about a day of mine

Rough edges

Nothing here changes how a run plays. These are the things someone new would trip on before they get to the game itself. You barely need to do anything for them.

1

Pause the run when the window loses focus

Yes45 minme
Today

Builds switch “run in background” off (RunInBackgroundOff.cs), so alt-tabbing freezes the game. When you come back, the fight resumes on the same frame with no menu in between. SettingsStore already hears the window lose focus, but only uses it to save settings.

Change

Losing focus during a run opens the pause menu. It doesn’t fire on the death or victory card, or during the loading screen.

2

Hide the mouse pointer during a run

Yes30 minme
Today

Nothing in the game hides the pointer, so it sits over the arena for the whole run, though a run never uses the mouse.

Change

The pointer hides when a run starts and comes back whenever a menu is open.

3

Show the build on the title screen and the pause menu

Yes1 hme
Today

Nothing on screen says which build is running. On 29 September I credited a build with a change that was committed 14 minutes after the build was made. A stamp on screen would have caught that, and it means every screenshot you send says which build it came from.

Change

A build step writes the build folder’s name and the commit into the game. The title screen and the pause menu show them, small, in a corner: 26_0929-1431 · 6fd5d30.

4

Teach each control when it first matters, in the buttons you’re holding

Yes4 hme, then you read the wording
Today

The game has one prompt, “Shift - Reverse”, shown for five seconds at the start. It still says Shift on a pad, where Reverse is LB. Dash, Slow Mo and the Deflector are never introduced: their bars show a name but no button.

The first upgrade offer isn’t explained either. Three pickups appear on the ring, and nothing says that taking one gives up the other two.

Change

One short line per control, at the moment it first matters:

  • Reverse and Dash in the first seconds of a run.
  • Slow Mo and the Deflector the first time you take them.
  • One line on the first offer.

Each line names the key or the pad button, whichever you used last. The hints show in your first three runs and then stop. Item 5 gives a way to bring them back.

You judge

Whether each line reads at a glance in the middle of a fight.

5

Add a Controls tab to Options

Yes2 hme
Today

Options has three tabs, Audio, Display and Graphics, since 30 September. Nothing in the game lists the controls.

Change

A fourth tab, which LB and RB reach like the others. It lists every action with its key and its pad button. If you say yes to 12 it holds the Rumble switch, and if you say yes to 4 it holds “Show hints again”.

6

Remember your best runs

Yes2–3 hme
Today

The end card sums up the run: time survived, level, kills, experience, and how often you took each skill. Press Try Again and all of it is gone.

Change

The game keeps your longest survival, highest level and fastest Leviathan kill, saved the same way as the settings. The end card says “New best” when you beat one, and the title screen shows all three.

7

Check the arena’s colours for colour blindness

Yes1.5 hme · a report
Today

Several things you have to tell apart differ mainly by colour: green salvage, the red pods on the Leviathan, orange lava behind everything. Red and green are the pair the most common colour blindness merges, and during the boss fight salvage drops from its hull plates, right beside the pods.

Change

The game screenshots itself in play. I run those frames through simulations of the three common kinds of colour blindness and report what merges. Nothing changes unless something does.

Phase 2 · one build · about a day and a half of mine

Moments and sound

These change how a run feels, so each one names the single number to turn if it’s wrong. From you: about half an hour picking sounds, then one run.

8

Put a beat between the killing hit and the Ship Lost card

Yes2–3 hyou judge the length
Today

The card goes up on the same frame as the killing hit, and time stops with it. You never see the shot that killed you land.

Change

About 1.2 seconds between the hit and the card. Time slows to a quarter, the ship breaks up and the music fades, then the card comes up as it does now. RunTime, which already sets the game’s speed, runs the beat. Pause stays blocked through it, as it is on the card.

The dial

The 1.2 seconds.

9

Freeze for a moment when the Leviathan loses a part

Yes1.5 hyou judge the feel
Today

When an emplacement goes down or an act ends, the game doesn’t pause at all. It feels no different from a Scout dying.

Change

A freeze of about 70 ms when an emplacement goes down, and about 150 ms when an act ends. Hull plates break every half second and ordinary kills come twice a second, so freezing on those would stutter. They stay as they are.

The dial

The two lengths.

10

Sound a horn before the Leviathan arrives

Yes2 hyou pick the horn
Today

The countdown bar runs out and the Leviathan is simply there. You reverted the 8 September pass that put phase names on screen, so this adds no text at all.

Change

Ten seconds before it arrives, a low horn sounds from far off. A second horn sounds as it arrives.

If silent

My first choice of three candidates.

11

Warn you on your last hit point

Yes2 hyou pick the sound
Today

On your last hit point, the only sign is the bar in the corner, and a player who is dodging is watching the ship.

Change

The health bar pulses slowly and a soft heartbeat plays until salvage takes you off your last hit point.

The dial

Whether it starts at one hit point or two. If you say nothing: the pulse plus my first choice of sound.

12

Rumble on a controller

Yes2 ha real pad, in the same run as the pad check
Today

A pad never rumbles. When you’re hit, the health bar flinches and the screen stays still, on purpose, because the camera already orbits. Rumble tells you the same thing through your hands without moving anything on screen.

Change

A short pulse on a hit, a dash, and an emplacement going down, and a longer one on death. The switch is on the Controls tab (5).

13

Give five moments their own sound

Yes3 hyou pick, about 20 minutes
Today

The game has 14 sounds. Five moments have no sound, or borrow another one’s:

  • Salvage plays the upgrade sound, so +1 HP sounds like a new skill.
  • The Deflector makes no sound when it blocks a hit.
  • Nothing marks Slow Mo starting or running out. The sound effects slow down with it, but there’s no cue for the switch.
  • An offer flashes silently through its last three seconds.
  • An act ending has no sound of its own.
Change

Five new sounds, with three candidates for each from the Kenney and Sonniss packs already in the project. The existing sound balancer sets their levels, so the rest of the mix stays where it is.

If silent

My first choice of each three.

14

Let the music answer pause and Slow Mo

Yes2 hyou listen
Today

The run’s track plays on unchanged under the pause menu and through Slow Mo. Only the sound effects slow down with the game.

Change

When you pause, the music drops and goes muffled until you resume. In Slow Mo its pitch dips slightly and comes back up as the bar runs out.

The dial

How far each one dips.

Later

Waiting on something

Both are worth doing, but one needs a track and the other only pays off once other people play the game.

15

Give the Leviathan its own music

Later1 hyou choose the track
Today

The project has two tracks, one for the menu and one for the run, and the Leviathan is fought to the run’s track.

Change

A third track fades in with the horn (10). Only you can choose music, and it has to come with a licence you’re happy with. Once you have a track, the fade takes an hour.

16

Let the keys be rebound

Not now1.5 daysme
Today

The game reads each key directly (Shift, Space, E, Esc), so none of them can be moved. Reverse fires when you let go of Shift, which is unusual, so it’s the first key a new player would want to move.

Change

Move input onto Input System actions and add a rebind for each action on the Controls tab. The game reads input through one interface, so no gameplay script changes. It’s worth it once other people play the game, and not before.

How it would ship

  1. Build 1: items 1 to 7. It doesn’t change how a run plays, so you can use it in place of newDrivers for the seven checks in the box above.
  2. Your run. Those seven checks, as on the open list. If you don’t mention one, its default stands, as usual.
  3. Build 2: items 8 to 14. The open list’s start-here card gets one line to watch for each item. For each one you don’t flag, the answer written on it stands.
  4. 15 and 16 wait until a track turns up, or until someone else is going to play the game.

Left out because you already decided

  • Screen shake. The health bar flinches instead, because the camera already orbits. Item 12 keeps to that.
  • Phase names on screen in the boss fight. Reverted on 8 September. Item 10 adds sound only.
  • The fireflies. Left out for good on 28 September.
  • FSR 3 frame generation. It needs control of the swap chain, which Unity keeps.
  • Trails behind the rounds. They drift off their rounds under FSR.

New enemies, new skills, a second boss, difficulty settings and an endless mode aren’t polish. They would make a content roadmap, which I can write if you want one.
